# reference/source_documents/

Text extractions of the three design documents this system was built from (originals live in D:\Downloads):

- `total_prompts.txt` — "Total Prompts (for ER agent).pdf": the original 8 module prompts (extraction, processing, two analysis passes, valuation/moat, management signaling, promoter quality, report generation)
- `er_architecture.md` — "ER agent architecture.docx": report-structure critique, the design brief (docling/langextract/yfinance, model tiering, ≤12pp, dynamic-not-flow), and architecture guidance (verification wave, JSON working format, deterministic data, rule-based triage)
- `deep_research.md` — "TBD Deep Research for company & sector (for ER agent).docx": DR1 company/regulatory research prompts + DR2 peer identification + the 7 sector packs + generic pack

`docs/DESIGN_DECISIONS.md` maps every deviation from these documents to its reason.
