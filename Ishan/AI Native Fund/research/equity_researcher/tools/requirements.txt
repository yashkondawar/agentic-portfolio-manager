# imports them, and it skips its two web-fallback scenarios when they are absent.
#
# Install status is deliberately NOT asserted here any more. A previous header
# claimed "verified installed <date>" and was wrong twice: once when the repo moved
# and the interpreter changed (markitdown/pdfplumber/pypdf/pandas/yfinance/openpyxl
# had silently vanished, breaking step 0.5 CONVERT, the market-data pull and the
# xlsx export), and again on 2026-08-03 when `bse` below was declared but absent —
# which is what made the offline test unrunnable. A comment cannot know what is
# installed; run the preflight check instead.
